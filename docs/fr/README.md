# Parcours francais : paymaster (sponsoring de gas ERC-4337 sur Base)

Lecture commentee du depot base/paymaster : un contrat Solidity qui accepte de payer le gas d une UserOperation ERC-4337 sur la foi d une signature externe, et le paquet Go qui produit cette signature.

Sommaire :

Chapitre 1 Presentation de paymaster. Chapitre 2 Le contrat Paymaster.sol. Chapitre 3 Le flux de validation on-chain. Chapitre 4 Le paquet signer en Go. Chapitre 5 Le flux cote client, paymaster.base.org. Chapitre 6 Limites et perimetre de ce parcours.

Ce parcours est une lecture pedagogique du code source et de la documentation du depot, sans installation ni execution du projet.
